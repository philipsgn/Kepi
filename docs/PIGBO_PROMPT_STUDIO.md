# 🎨 BỘ PROMPT CHUẨN STUDIO: MASCOT CHÚ HEO PIGBO (3D CLAY CHIBI)

> **Mục đích:** Bộ câu lệnh tạo ảnh tiêu chuẩn chuyên nghiệp cho Midjourney v6, ChatGPT Plus (DALL-E 3), hoặc Google Imagen 3 để tạo ra bộ hình ảnh Chú Heo PigBo chất lượng 4K chuẩn studio.

---

## 🌟 1. ĐẶC TẢ TẠO HÌNH CỐT LÕI (CORE MASCOT SPECIFICATION)
- **Nhân vật:** Chú heo đất Chibi béo tròn dễ thương (Cute Chubby Porcelain Piglet / Piggy Bank).
- **Chất liệu & Bề mặt:** 3D Clay Chibi đất nặn mịn màng phong cách hoạt hình Pixar/Popmart (Smooth porcelain ceramic with matte clay finish, soft ambient occlusion, subsurface scattering).
- **Màu sắc:** Thân màu **Trắng Sứ ngọc trai** (`#FFFDF9`), tai trong và mũi má màu **Hồng phấn pastel** (`#FFB6C1`).
- **Nền:** Trong suốt tuyệt đối hoặc nền xanh mint sáng (`isolated on transparent background, PNG`).

## 💡 3. HƯỚNG DẪN SỬ DỤNG:
1. Mở **ChatGPT Plus (GPT-4o)** hoặc **Midjourney**.
2. Dán nguyên văn đoạn code prompt tương ứng ở trên.
3. Tải file kết quả về, dùng công cụ tách nền miễn phí (như `remove.bg` hoặc Photoshop) để lưu file PNG trong suốt vào thư mục `assets/pigbo/`.
